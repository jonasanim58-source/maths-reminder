MATHS REMINDER – TEACHER EDITION

Files:
- index.html: the app
- manifest.json: install metadata
- sw.js: offline caching

Important notification limitation:
This first version checks lesson times while the app is open. Android/Chrome may pause web-app timers when the app is backgrounded or closed, so it cannot guarantee alarms when fully closed. A truly reliable closed-app alarm requires a native Android app or a push/notification backend.

To use:
1. Upload the folder to a static HTTPS host (for example GitHub Pages) or open it through a local web server.
2. Open the HTTPS site in Chrome on Android.
3. Use Chrome menu > Add to Home screen / Install app.
4. Open the installed app, tap Enable notifications, allow permission, then tap Start reminders.
5. Keep it open for reminder checks.
